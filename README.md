# Odoo 20 - UNICAH

Proyecto académico de instalación y ejecución de Odoo 20 desde código fuente.

## Tecnologías utilizadas
- Python 3.12
- PostgreSQL 16
- Docker Desktop
- Visual Studio Code
- Git y GitHub

## Instalación
El código fuente de Odoo 20 se obtuvo desde:
https://github.com/odoo/odoo

## Configuración
- PostgreSQL en Docker
- Puerto de PostgreSQL: 5433
- Puerto de Odoo: 8069
- Entorno virtual de Python (.venv)

## Ejecución
Desde la carpeta del código fuente de Odoo:

python odoo-bin -c odoo.conf

Abrir http://localhost:8069
